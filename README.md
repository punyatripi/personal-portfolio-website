# Personal Portfolio Website

A simple personal portfolio website built as a Mini Project for my B.Sc. in
Computer Science (Semester 3) at the National Institute of Speech and Hearing
(NISH), December 2020.

## Built with
- HTML
- CSS
- JavaScript (jQuery)
- Google Fonts (Montserrat)

## How to run
1. Clone or download this repository.
2. Open `firstwebsite.html` in a browser.
